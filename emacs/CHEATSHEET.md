# Emacs 快捷键速查表

配置：`dotfiles/emacs/.emacs`（GNU Emacs 30.2，软链接 `~/.emacs`）

> 约定：`C-` = Ctrl，`M-` = Alt/Option（终端里通常是 Esc 前缀），`S-` = Shift
> 建议学习顺序：先读"零、理解键位前缀" → 基础移动 → 编辑操作 → 搜索补全 → LSP → 其他

## 原生键 vs 自定义键（一眼分清）

**原生键 = Emacs 自带，开箱即用，无需配置，任何 Emacs 都一样**：

| 按键 | 功能 | 按键 | 功能 |
|---|---|---|---|
| `C-f`/`C-b`/`C-p`/`C-n` | 上下左右移 | `C-a`/`C-e` | 行首/行尾 |
| `M-f`/`M-b` | 跳词 | `M-<`/`M->` | 文件首/尾 |
| `C-v`/`M-v` | 翻页 | `C-l` | 屏幕居中 |
| `C-d`/`DEL` | 删字符 | `M-d`/`M-DEL` | 删词 |
| `C-k` | 删到行尾 | `C-y` | 粘贴 |
| `C-/` | 撤销 | `M-;` | 智能注释 |
| `C-x C-f` | 打开文件 | `C-x C-s` | 保存 |
| `C-x 2`/`3`/`0`/`1`/`o` | 窗口操作 | `C-x k` | 关 buffer |
| `M-.`/`M-,`/`M-?` | 定义/跳回/引用 | `C-h f`/`v`/`o` | 文档查询 |
| `M-x` | 命令入口 | `M-u`/`M-l`/`M-c` | 单词大小写（原生版） |

**自定义键 = 我在这份配置里加的，只有你的 Emacs 有**：

| 按键 | 功能 | 类型 |
|---|---|---|
| `C-c f` | 格式化 | 新增 |
| `C-c t`/`T`/`C-t` | 折叠/全折叠/全展开 | 新增 |
| `C-c d`/`D` | 诊断列表 | 新增 |
| `C-c a`/`r`/`i` | LSP 操作/重命名/整理导入 | 新增 |
| `C-c c` | 编译 | 新增 |
| `C-c C-r` | 热加载配置 | 新增 |
| `C-c ;`/`b` | 行注释/块注释 | 新增 |
| `C-c k`/`K` | 删行首/删整行 | 新增 |
| `C-o` | 下方开新行（原生是原地开行） | **改绑** |
| `C-s` | 文件内搜索（原生是 isearch） | **改绑** |
| `C-S-s` | 全项目搜索 | 新增 |
| `C-x b` | 切 buffer 增强（原生 switch-to-buffer） | **改绑** |
| `C-w`/`M-w` | 复制/剪切（与原生互换） | **改绑** |
| `M-u`/`M-l`/`M-c` | 大小写整词版（原生只处理半截） | **改绑** |
| `M-<up/down>` | 移行 | 新增 |
| `M-S-<up/down>` | 复制行 | 新增 |
| `C-=`/`C-M-=` | 扩展/收缩选区 | 新增 |

**改绑 = 占用了原生键但改了行为**，看到这些键记住"不是原生的"。

## 零、理解键位前缀（先记这个，其他都好办）

Emacs 的键位**按前缀分区**，每个前缀管一类事情。看到键位先认前缀，就知道它大概是什么：

| 前缀                      | 管什么                         | 例子                                 |
| ------------------------- | ------------------------------ | ------------------------------------ |
| **无前缀**（`C-f` `M-f`） | 编辑操作：移动、删改           | `C-f` 前进、`M-f` 跳词               |
| **`C-x`**                 | 系统操作：文件 / 窗口 / buffer | `C-x C-f` 开文件、`C-x 2` 分窗       |
| **`C-c`**                 | 我配置的自定义功能 + 模式命令  | `C-c f` 格式化、`C-c t` 折叠         |
| **`C-h`**                 | 帮助                           | `C-h k` 查这个键、`C-h b` 列出所有键 |
| **`M-x`**                 | 命令入口：输入任意命令名       | `M-x compile`                        |
| **`C-M-`**                | 结构级：括号、函数、代码块     | `C-M-f` 跳括号、`C-M-a` 函数头       |

**记忆口诀**：

- `C-x` = e**X**ecute（系统级操作，像命令行）
- `C-c` = **C**ustom（你自己的东西都在这里）
- `C-h` = **H**elp
- `M-x` = e**x**ecute 任意命令（命令的入口）
- `M-` = 单词级操作（词 = M）
- `C-M-` = 结构级操作（更大的单位）

**再看一层：修饰键决定"操作单位"**（同一个字母，前缀越大，单位越大）：

| 键            | 功能                       | 单位    |
| ------------- | -------------------------- | ------- |
| `C-f`         | 前进 1 字符                | 字符    |
| `M-f`         | 前进 1 单词                | 单词    |
| `C-M-f`       | 跳到配对括号（整个表达式） | 结构    |
| `C-a` / `M-a` | 行首 / 句首                | 行 / 句 |
| `C-e` / `M-e` | 行尾 / 句尾                | 行 / 句 |

**你的自定义键位全在 `C-c` 区**（本配置），就这么些：

| `C-c` +               | 功能                         | 记忆                                 |
| --------------------- | ---------------------------- | ------------------------------------ |
| `C-c f`               | 格式化                       | **F**ormat                           |
| `C-c t` / `T` / `C-t` | 折叠 / 全折叠 / 全展开       | **T**reesit                          |
| `C-c ;` / `b`         | 行注释 / 块注释              | 分号=行，b=**B**lock                 |
| `C-c d` / `D`         | 诊断：当前文件 / 项目        | **D**iagnostic                       |
| `C-c a` / `r` / `i`   | LSP 操作 / 重命名 / 整理导入 | **A**ction / **R**ename / **I**mport |
| `C-c c`               | 编译                         | **C**ompile                          |

## 一、基础移动（Emacs 原生，必学）

| 快捷键            | 功能                                    |
| ----------------- | --------------------------------------- |
| `C-f` / `C-b`     | 光标 前/后 移一个字符                   |
| `C-p` / `C-n`     | 光标 上/下 移一行                       |
| `C-a` / `C-e`     | 行首 / 行尾                             |
| `M-f` / `M-b`     | 跳过 后/前 一个单词                     |
| `M-<` / `M->`     | 文件开头 / 文件结尾                     |
| `C-v` / `M-v`     | 下/上 翻页                              |
| `C-M-f` / `C-M-b` | 后/前 跳到配对括号（跨表达式）          |
| `C-l`             | 屏幕居中滚动光标行                      |
| `C-s`             | 向后搜索（见搜索节，已换 consult-line） |

## 二、编辑操作

| 快捷键                    | 功能                                                    |
| ------------------------- | ------------------------------------------------------- |
| `C-o`                     | 当前行下方开新行（光标移入）                            |
| `M-<up>` / `M-<down>`     | 整行 上/下 移动                                         |
| `M-S-<up>` / `M-S-<down>` | 整行 上/下 复制                                         |
| `C-c ;`                   | 行注释 / 取消（当前行）                                 |
| `C-c b`                   | 块注释 / 取消（需先选中区域）                           |
| `C-=` / `C-M-=`           | 扩展 / 收缩选区（连按逐步扩大）                         |
| `C->` / `C-<`             | 多光标：下一个 / 上一个相同词加光标（连按继续加）       |
| `C-c M`                   | 多光标：选中区域后标记**所有**相同词                    |
| `C-c m`                   | 多光标：选中多行后每行一个光标（edit-lines）            |
| `M-u` / `M-l` / `M-c`     | 单词 大写 / 小写 / 首字母大写（整词；有选区则处理选区） |
| `C-x C-;`                 | 注释选中区域（原生）                                    |
| `TAB`                     | 行首/缩进位置 = 缩进；文本中间 = 插入 tab（已配置）     |

## 三、删除与复制（原生）

| 快捷键          | 功能                                                 |
| --------------- | ---------------------------------------------------- |
| `C-d` / `DEL`   | 删 后/前 一个字符                                    |
| `M-d` / `M-DEL` | 删 后/前 一个单词                                    |
| `C-k`           | 删光标到行尾（连按含换行）                           |
| `C-c k`         | 删光标到行首（与 C-k 对称）                          |
| `C-c K`         | 删整行（含换行，光标在行内任意位置）                 |

| `C-w`           | 复制选中区域（已与 M-w 互换）                        |
| `M-w`           | 剪切选中区域（已与 C-w 互换）                        |
| `C-y`           | 粘贴（终端模式走系统剪贴板 pbcopy/pbpaste）          |

## 六、补全

| 操作          | 说明                                                    |
| ------------- | ------------------------------------------------------- |
| 输入即弹      | corfu 代码补全：输入 2 字符后自动弹出候选               |

## 六点五、可视辅助（缩进线 / 彩色括号 / telescope 对应）

| 功能 | 说明 |
|---|---|
| 缩进线 | `indent-bars`：代码块缩进处显示树形竖线（treesitter 驱动） |
| 彩色括号 | `rainbow-delimiters`：`( ) [ ] { }` 按嵌套深度着色，一眼看出配对 |
| telescope 对应 | 就是 **consult**：`C-x b` 切 buffer、`C-s` 文件内搜、`C-S-s` 项目 grep、`C-x C-f` 开文件（模糊匹配，等价 nvim telescope） |

## 七、代码跳转与文档查询（xref，eglot 自动接管）

| 快捷键 | 功能 |
|---|---|
| `M-.` | **跳到定义**（函数/变量/常量/宏；LSP 下走服务器精确跳转） |
| `M-,` | **跳回来**（返回上一个位置，可连续回退） |
| `M-?` | 查找所有引用（谁在用这个符号） |
| `C-x 4 .` | 在另一窗口打开定义（原窗口保留） |
| `C-x 5 .` | 在另一帧打开定义 |
| `C-u M-.` | 列出多个定义供选择（重载/同名符号时） |
| `M-x xref-find-apropos` | 按名字搜符号（模糊搜定义） |
| `C-h f` | 查函数文档（参数/说明） |
| `C-h v` | 查变量/常量文档 |
| `C-h o` | 查任意符号（函数/变量/宏统一搜） |
| `C-h k` | 查某个按键绑定的是什么命令 |

> 说明：这些是 Emacs 原生键，eglot 连接后 `M-.` 等自动走 LSP（如 gopls 跳 Go 定义、clangd 跳 C 宏）。elisp 文件里 `M-.` 跳 elisp 定义，`C-h f/v/o` 查 elisp 文档。

## 备注

- 主题：gruvbox（`M-x load-theme` 可临时切换）
- 终端兼容：corfu-terminal 自动启用，`M-<up>` 等组合键在部分终端可能被占用
- 格式化工具链：go→goimports、python→ruff、rust→rustfmt、c/cpp→clang-format、bash→shfmt、json→jq、markdown→prettier（与 nvim 一致）
- 配置文件改动后：重启 Emacs 或 `M-x eval-buffer` 生效
